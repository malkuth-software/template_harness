# claude/: the FranSushi marketplace inside the harness

A Claude Code plugin marketplace named `fransushi`
(`.claude-plugin/marketplace.json`) holding the seven FranSushi plugins in
`plugins/`, plus the harness's single house rule pack in `rules/`.

- `plugins/` and `.claude-plugin/marketplace.json` are copies, written by
  `python3 harness/sync_fransushi.py --from <fransushi clone>` from the
  private development repository. `FRANSUSHI.lock` records the source commit
  and each plugin's version. Never edit the copies; change the source and
  sync again.
- `rules/house.json` is the house rule pack: the mechanical part of
  `HOUSE_STYLE.md` (canonical, `main` of the notes repository). Each rule
  cites its HOUSE_STYLE section and has a fail and a pass fixture in
  `rules/fixtures/`. SushiStyle reads it through an app's
  `.sushi/sushistyle.json` (`"rule_packs": ["../template_harness/claude/rules/house.json"]`).

An app generated by `new_app` declares this marketplace in its committed
`.claude/settings.json` (a github source: this repository, path
`claude/.claude-plugin/marketplace.json`, `ref` the `harness.lock` commit) and
enables every plugin except sushidelivery. `lock.py bump` moves that ref with
the lock.

Validate: `claude plugin validate claude`, and each plugin with
`claude plugin validate --profile directory claude/plugins/<name>`.
