# {{title}}

A GUI.Forms application, built with the shared harness
([`{{harness_repository}}`](https://github.com/{{harness_repository}})) at the
commit `harness.lock` pins. It was generated by the harness's `new_app`
command from `templates/app/`.

## Workspace

The harness contract's sibling layout:

```text
<workspace>/{{app}}               this checkout
<workspace>/template_harness      the harness, at the harness.lock commit
<workspace>/notes, notes-{{app}}  the notes and this app's notes branch
<workspace>/projects              coordination: tracks, seats, desks (in-house)
<workspace>/.build, .ccache, .ci  build trees and caches
```

Set it up on a clean machine with the harness bootstrap:

```sh
gh repo clone {{harness_repository}} && sh template_harness/bootstrap.sh --workspace DIR --project {{app}} --in-house
```

## Build and test

From the workspace root, on a build host with LLVM 22.1.8, CMake and Ninja
(never on a machine that must not compile):

```sh
python3 {{app}}/ci_build.py --jobs 4 --allow-network-inputs
python3 {{app}}/ci_build.py --gui-forms-prefix "$(python3 template_harness/harness/lockstep.py prefix)"
python3 -B -m unittest discover -s {{app}} -p "test_*.py"
```

`gui_forms.lock` pins the GUI.Forms source SDK; `fetch_sdk.py pin TAG` moves it.

| Path | What |
|---|---|
| `src/`, `tests/` | the app's form, its entry point and the form's test |
| `CMakeLists.txt`, `ci_build.py`, `fetch_sdk.py`, `gui_forms.lock` | the build against the pinned GUI.Forms SDK |
| `harness.lock` | the harness pin; `lock.py bump` also moves the plugin marketplace ref |
| `.github/workflows/ci.yml` | CI through the harness's reusable workflows at the same commit |
| `CLAUDE.md`, `AGENTS.md`, `.claude/` | agent instructions, project agents and the FranSushi plugins |
| `.sushi/*.json` | the plugins' project configuration |
